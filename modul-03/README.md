# ALPRO-A-Challenge (Python)

Repositori resmi pengumpulan challenge dan asistensi **Algoritma dan Pemrograman (Kelas SI-A)**.

---

## 🚀 Alur Pengumpulan Tugas

1. **Fork & Clone**
   - Klik tombol **Fork** di pojok kanan atas repo ini.
   - Clone repo hasil fork ke laptop Anda:
     ```bash
     git clone 
     cd alpro-a-challenge
     ```

2. **Ekstrak & Kerjakan Tugas**
   - Unduh dan ekstrak file soal `.zip` yang diberikan asisten.
   - Masuk ke folder `modul-03/submissions/`.
   - Buat folder identitas Anda sendiri:
     ```text
     [NIM]_[NAMA]_[MODUL]
     ```
     *Contoh:* `modul-03/submissions/250441100081_Nanggala_Modul03/`
   - Pindahkan file soal dan kerjakan kodingan Python (`.py`) Anda di dalam folder tersebut.
   *(Peringatan: Jangan memasukkan file mentah `.zip` atau `.pdf` ke dalam repo)*.

3. **Simpan, Push, & Pull Request**
   - Di terminal, jalankan:
     ```bash
     git add .
     git commit -m "submit challenge modul 03"
     git push origin main
     ```
   - Buka repo GitHub Anda di browser, klik **Compare & pull request**.
   - Beri judul PR: `[Modul 03] NIM - Nama Lengkap`, lalu klik **Create pull request**.
